# Food app

Starter foundation for an application built with Next.js, React, TypeScript, and Tailwind CSS.

## Requirements

- Node.js 22 or newer
- npm

## Development

```sh
npm install
npm run dev
```

Next.js prints the local application URL in the terminal.

## Checks and build

```sh
npm run lint
npm run build
```

For production, run `npm run build`, then `npm run start`.

## Stack

- React 19
- TypeScript
- Next.js App Router
- Tailwind CSS 4
- ESLint
